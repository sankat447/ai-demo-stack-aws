# AI Demo Stack on AWS — Team Onboarding

End-to-end runbook to provision and tear down the OCP 4.21 + RHOAI + ArgoCD demo stack on AWS, starting from nothing on your laptop.

**ETA**: 60-90 min unattended for first-time provision. Teardown ~30 min.
**Cost while running**: ~$1.55/hr ($37/day, $1,123/month). Always tear down when not actively using.

---

## 0. What you'll get

A working OpenShift 4.21 cluster on AWS with:

- 3 control-plane + 2 worker nodes + autoscaling compute + GPU pools
- Aurora PostgreSQL 16.4 with pgvector
- EFS shared storage
- 28 GitOps-managed applications (RHOAI, KServe, vLLM, langchain, n8n, vault, grafana, keycloak, mlflow, minio, portkey, redis, mongodb, open-webui, jaeger, kiali, etc.)
- TLS-secured routes at `*.apps.ai-demo.iisdemolab.click`

## 3. Provision (shell flow)

```bash
./deploy.sh
```

That's it. The script is interactive but only needs:
- `y` at the "Proceed with deployment?" prompt
- A browser tab for AWS SSO login (auto-opens)
- A browser tab for Red Hat SSO login (auto-opens)
- Pull secret paste **only if** `.pull-secret.json` doesn't exist yet (deploy.sh opens the URL for you)

What happens (~45-55 min total):

| Phase | What | Duration |
|---|---|---|
| 0.1-0.4 | Tool check, SSO auth, tfvars generation, IAM key auto-create | ~2 min |
| 1.0-1.2 | Terraform state backend + targeted `module.ocp` apply (OCP IPI install) | ~35 min |
| 1.3 | Full terraform apply — Aurora + EFS in OCP VPC | ~7 min |
| 2 | Wait for cluster operators stable | ~2 min |
| 3 | ArgoCD bootstrap + 28 apps sync | ~5 min |
| 4 | Quality check | ~1 min |

At the end you'll see:
```
DEPLOYMENT COMPLETE
Console:  https://console-openshift-console.apps.ai-demo.iisdemolab.click
ArgoCD:   https://openshift-gitops-server-openshift-gitops.apps.ai-demo.iisdemolab.click
…
```

### 3.1 Get credentials after deploy

```bash
export KUBECONFIG=$PWD/environments/demo/ocp-install-dir/ai-demo/auth/kubeconfig

# OCP kubeadmin password
cat $PWD/environments/demo/ocp-install-dir/ai-demo/auth/kubeadmin-password

# ArgoCD admin password (auto-generated by GitOps Operator)
oc -n openshift-gitops get secret openshift-gitops-cluster \
  -o jsonpath='{.data.admin\.password}' | base64 -d ; echo

# Verify cluster
oc get nodes
oc get applications.argoproj.io -n openshift-gitops
```

Expect **25/28 apps Healthy** within ~10 min of bootstrap. The 3 transient OutOfSync ones (`gpu-operator`, `llama-inference`, `vllm-runtime`) clear as KServe/NFD finish registering.

### 3.2 If deploy fails

**`AccessKeysPerUser: 2`** at PHASE 0.4 → IAM user already has max keys (someone else on the team provisioned). Fix:
```bash
aws iam list-access-keys --user-name ocp-installer --profile rhoai-demo
aws iam delete-access-key --user-name ocp-installer --access-key-id <oldest> --profile rhoai-demo
rm -f .ocp-installer-creds.json
./deploy.sh   # retry
```

**`No matching EC2 VPC found`** for `data.aws_vpc.ocp` → 2-phase apply tripped. Re-run `./deploy.sh` (idempotent).

**Anything else** → check `logs/deploy_<timestamp>.log`. Compare against [`docs/LESSONS_LEARNED.md`](docs/LESSONS_LEARNED.md) for likely causes.

## 8. Deprovision (full teardown)

```bash
./destroy.sh
# Type 'destroy-demo' at the confirmation prompt
```

Takes ~25-30 min. Phases:
1. ArgoCD apps removed (lets RHOAI clean its own webhooks)
2. **Phase 2.5: Aurora + EFS destroyed FIRST** (critical — see lesson #13)
3. `openshift-install destroy cluster` — terminates EC2, ELBs, IGW, NAT, VPC
4-6. Orphan cleanup (cross-VPC EFS mount targets, residual EIPs, VPC peering remnants)
7. `terraform destroy` for remaining infra
8. Verification
9. Residual cleanup (SSM params, RDS subnet/parameter groups, local state files)

When it says `TEARDOWN COMPLETE`, cost drops to **$0/hr** (the S3 state bucket itself costs cents/month).

### If teardown gets stuck

Look for "Deleted NAT gateway=... " repeating on the same IDs forever — that's the lesson #13 symptom. Kill the script and run:
```bash
cd environments/demo
AWS_PROFILE=rhoai-demo terraform destroy \
  -target=module.aurora -target=module.efs \
  -target=aws_security_group.aurora_ocp -target=aws_security_group.efs_ocp \
  -target=null_resource.efs_storage_class -auto-approve
cd ../..
./destroy.sh    # resume — phases are idempotent
```
